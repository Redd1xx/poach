# Poach: Zero-CAC Competitor Displacer & Space CMS Studio

> Turn verified competitor defects, negative reviews, and user friction into high-converting displacement switch pages, strategic battlecards, and Frevana Space CMS publications. Built with Frevana for the SF Tech Week Frevana Agent App Hackathon.

![Poach Logo](logo.png)

## Overview
Founders and growth marketers spend thousands on paid ads trying to acquire customers who are already fed up with incumbents. **Poach** autonomously extracts high-frequency defects from verified competitor reviews (Amazon, G2, Reddit), computes customer churn velocity, formulates high-converting positioning wedges, and generates publication-grade head-to-head displacement landing pages published directly to Frevana Space CMS.

## Features
- **Zero-CAC Competitor Displacement**: Scans competitor pain points and verified customer complaints to build authentic conversion wedges.
- **1-Click Battleground Benchmark Presets**:
  - *Jira Software $\rightarrow$ Linear* (Latency, indexing overhead, issue bloat)
  - *Salesforce Enterprise $\rightarrow$ Attio* (Admin tax, inflexible data modeling, multi-month onboarding)
  - *Dyson V15 $\rightarrow$ Shark Stratos* (Hair wrap maintenance, battery degradation, trigger fatigue)
  - *Notion Teams $\rightarrow$ Obsidian* (Offline reliability, proprietary format lock-in, mobile startup lag)
  - *HubSpot CRM $\rightarrow$ Loops* (Contact tier pricing traps, marketing seat penalties, transactional deliverability)
- **Real-Time Defect Cluster Radar**: Interactive visual radar breaking down Latency, Admin Tax, Dark Pattern Pricing, and Migration Lock-in with frustration percentages and verified customer citations.
- **Live Churn Velocity Ticker**: Dynamic marquee tracking real-time verified customer frustration signals and churn latency scores.
- **Strategic Wedges & Space CMS Editor**: Two-way synced Markdown editor and live rendered switch page preview with 1-click publishing to Frevana Space CMS.
- **Full Specification Matrix**: Comprehensive comparison grid comparing incumbent vs. displacer across P95 latency, time-to-value, contract terms, and seat minimums.
- **Multi-Format Export Suite**: 1-click export to Markdown battlecard, JSON competitor dossier, or formatted clipboard copy.
- **Procedural Web Audio**: Built-in Web Audio synthesis providing crisp tactile acoustic feedback on clicks, tabs, and preset activations without external asset requests.
